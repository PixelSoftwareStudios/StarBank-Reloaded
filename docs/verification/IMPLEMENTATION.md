# Implementation evidence

## WP-03 bank XML

`sc2bank` parses bounded XML 1.0 in UTF-8 and BOM-marked UTF-16LE and UTF-16BE. It keeps original source bytes, ordered section/key/value occurrences and unknown markup. Export without changes returns the original bytes. Edits to recognized existing value attributes replace their original byte ranges, escape the inserted values and revalidate the result. Unsupported encodings, DTDs, invalid references, ambiguous edits and exceeded limits return typed errors.

The initial Rust 1.100.0 build passed 15 synthetic tests on macOS arm64 and built the crate for `wasm32-unknown-unknown`. The tests cover BOM and line endings, duplicate names, multiple and missing values, exact numeric lexemes, namespace discrimination, opaque markup, processing-instruction syntax and bounded failure cases. All 10 fixture digests matched. [Tests](../../crates/formats/sc2bank/tests/format.rs) · [Fixture provenance](../../crates/formats/sc2bank/tests/fixtures/README.md)

An isolated AddressSanitizer and libFuzzer smoke ran 114,685 inputs in 31 seconds at `8fbe402`, seeded from the 10 synthetic fixtures. The maintained harness later exercised 61,970 inputs in 21 seconds, including targeted scalar edits across all three supported encodings. Both runs completed with zero crashes or sanitizer reports. Two later 90-second AddressSanitizer runs at `3855597` exercised 267,922 scalar and 271,068 structural inputs with zero sanitizer failures or crash artifacts. [Pinned harness and reproduction](../../crates/formats/sc2bank/fuzz/README.md)

## WP-04 signature computation and verification

`starbank-signature` validates explicit author, player and bank-name context, computes the SHA-1 digest using stable UTF-16 ordinal ordering, and checks a stored signature without mutating the bank. It distinguishes unsigned, malformed, missing-context, unsupported, valid and invalid states. Eight Rust tests passed on macOS arm64. The WASM library built on Rust 1.100.0. [Tests](../../crates/domain/starbank-signature/tests/signatures.rs)

Synthetic digest and round-trip checks cover ordering, UTF-16 and signature state. SC2 game-generated conformance remains open. [Signature tests](../../crates/domain/starbank-signature/tests/signatures.rs)
