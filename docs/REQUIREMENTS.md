# Requirements register

All new requirements are **Pending implementation/verification**. `Required` is the intended native parity/release baseline, not a claim of current implementation. Browser-specific capability limits are documented. `Deferred` is explicitly postponed; `Proposed` retains earlier optional ideas without promoting them. IDs stable; acceptance cases below are the minimum, expand per feature.
