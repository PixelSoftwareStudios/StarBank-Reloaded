# Discovery, maps and MPQ

## Paths

`get_sc2_root_path()` (historical `GetSC2RootPath`) returns **first valid** auto-detected user-data root, not installation/executable path. Validate candidates as encountered; do not build then traverse a redundant list or scan whole disks. Return typed NotFound / PermissionDenied / NotImplemented / UnsupportedPlatform, with candidate diagnostics. Prefer actual existing Banks roots (including empty); distinguish valid SC2 root without banks. `get_bank_folder_from_root` returns all discovered account-scoped folders. `is_valid_bank_path` accepts a manually chosen Banks/root/Accounts and normalizes without inventing signing context. Separate `parse_signing_context(file)` from folder validation. Existence is not proof of signability. Accept empty authentic Banks and arbitrary selected bank collections; unknown folder shape requires explicit context. Use OS paths and case-insensitive extension check; do not require map folder names ending `.SC2Map`.

```text
StarCraft II/Accounts/<numeric account>/<player handle>/Banks/<author handle>/<bank name>.SC2Bank
```

That is a common canonical layout, not the only one. Preserve original Go convention `PlayerID`, `AuthorID` and upstream `PlayerNumber`, `AuthorNumber` mapping. Recursively handle nested, direct and legacy bank files (only scoped Banks subtree), detect hidden/unmapped banks, distinguish backups from live files; use actual path anchors, no fixed-depth guesses for nested paths. Group by stable player/author/map identity and real file, not bank basename only. Avoid duplicates across aliases and symlinks; avoid escaping selected directory or following loops, handle non-UTF8 paths using OS-native types. Permissions errors must be visible rather than treated as missing data.

Settings has Auto-detect/manual, selected path, Select Folder, Re-scan, clear override. Honor explicit override; invalid override stays visible, no silent selection of another account. Exact not-found copy: **No SC2 Bank Folder path auto-detected, please select a folder**. Linux separate unsupported auto-detection explanation plus same picker. Cancellation is not failure. No banks is distinct from no root, no matching search, unreadable path, incomplete indexing. Account selection uses settings or compact selector only when needed; no account label footer. Player display name best effort from reliable local file metadata or known profile; never infer signing identity from display name.

## Map index

Original Go `internal/mapinfo/cache.go` scans shared `/Users/Shared/Blizzard` (macOS) or `%ProgramData%/Blizzard Entertainment` (Windows), subpaths `StarCraft II/Maps/Cache`, `Battle.net/Cache`. Upstream v2.0 [MapInfoCache.cs](https://github.com/BlueRaja/Starbank/blob/v2.0/StarBank/MapInfoCache.cs) uses Windows common app data Battle.net cache and metadata from Galaxy script with DocumentHeader fallback. Validate native cache paths including optional manual cache location. Discover bank files independently so missing MPQ never blocks bank editing. Inspect `.s2ma`, `.SC2Map`, `.SC2Mod` where relevant; do not scan unrelated game data. Read `MapScript.galaxy`, known script path variants and `DocumentHeader`; extract known title/author, map flags, declared bank names (literal and statically resolved variable references), timestamp of cached file, metadata confidence. Decode complete byte sequence, not independent chunks. No running Galaxy code. Association is a hint, not a unique match: preserve collisions, player/author scopes, all candidates; let user resolve ambiguity. Latest cached version selection deterministic and not collapse unrelated authors. Unknown metadata stays unknown. Display actual map author/name/download time where known, not dummy text. Show cached maps with no banks if filter off. Unknown map entries with real banks visible.

Persistent versioned metadata cache (not necessarily binary-compatible `MapCache.dat`), key by archive path/identity, size, mtime, parser version; optional content hash for strict verification. Re-associate live bank inventory every run. Rebuild corrupt/stale entries, remove missing records, atomic cache writes, bounded size; no whole scripts retained. Read-only indexing; one archive open per changed map, one account inventory, deduped variable lookup or tokenization, avoid unanchored quadratic regex behavior. Max four workers default capped at available parallelism/2 (min one), bounded queue, cancellation and progress, no UI blocking or all-core saturation. Batch incremental results with generation IDs. Benchmark cold/warm with large scripts, many map revisions, no duplicated work. Use Rayon for CPU-bound work, bounded blocking workers for IO.

## MPQ selection spike

Candidates: [wow-mpq](https://crates.io/crates/wow-mpq), [stormlib-rs](https://github.com/notOrrytrout/stormlib-rs), [mpq](https://github.com/msierks/mpq-rust), [nom-mpq](https://github.com/sebosp/nom-mpq), [mpq-rs](https://crates.io/crates/mpq-rs), [ceres-mpq](https://crates.io/crates/ceres-mpq); compare [StormLib](https://github.com/ladislav-zezula/StormLib) as differential reference. Prefer pure Rust with permissive license; check actual crate versions/license, target/feature support and upstream activity from source at selection. No claim every MPQ variant or WASM is supported. Original Go uses icza/mpq read-only; earlier Go alternatives suprsokr/go-mpq and CGo bindings superseded. Read-only is enough for indexing but **not** archive repair/export. Choose backend only after open/extract/list/existence/authorized modification/verification tests on real SC2 map corpus, Unicode/large entries, encryption/compression variants, corrupt headers, absent listfile and protected archives. Limits on compressed/expanded sizes, offsets, counts, CPU, allocations; reject unsafe extraction paths. Stream/seek as supported; native path and byte-based WASM adapters separated; memory-map only after safety measurement. If no pure Rust backend meets native read/write parity, evaluate minimal audited StormLib FFI with per-OS build and license review. No need to own MPQ implementation or maintain C++ if not necessary.

Original [MapProtection.cs](https://github.com/BlueRaja/Starbank/blob/v2.0/StarBank/MapProtection.cs) concerns map archives, never bank XML. Preserve Tools action “Unprotect external map file…” for authorized local map repair/inspection and export, no automatic cache edits. Assess compatibility against component metadata and archive validity using authorized fixtures; maintain source copy, explicit confirmation and output path, verify resulting archive, no fabricated claim of recovering original triggers or breaking encryption. No runtime memory extraction, game trainer, server validation bypass or ban evasion. Capability disabled with meaningful reason if backend cannot safely support it. Web MPQ support conditional on WASM compatibility; native editor not blocked by it.
