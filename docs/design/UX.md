# UI specification — shared Desktop/Web

Approved direction: compact modern StarBank look, not a generic dashboard. Reference: [editor-reference.svg](editor-reference.svg), an illustrative reconstruction of the accepted dark UI concept, not executable UI. Existing `original/internal/ui/` is historical baseline; preserve decisions, not Fyne implementation details. No unrelated changes during bug fixes.

## Shell

Desktop starts at **850 × 500 logical pixels**, resizable; OS-native window chrome is fine, application menus inside app identical across Windows/macOS/Linux/browser. Outer content uses responsive flex/grid with min-width/min-height zero where needed, consistent insets, theme spacing tokens. Split left map panel about 28% (prototype) and right editor, adjustable and persisted. Narrow screens allow sidebar collapse/reflow with no lost controls; web adapt to mobile touch. Left Map List header left aligned + divider, search placeholder `Search maps…`, scrollable bounded/virtualized list fills remaining space; Quick Options pinned under it, not pushed offscreen. Search no expensive scans or unintended deselect. Exactly three default-checked options, capitalization fixed: `Hide Blizzard maps`, `Hide maps without bank files`, `Auto re-sign banks on save`. Quick Options title, divider; **More** link/button takes full settings page. No account label at bottom of list, no `StarBank Reloaded <spacer> v1.0.0` branding footer (explicitly removed after gray/font/margin experiments). Account switching in clean picker/settings, optional contextual player name when reliable, not a reinstated footer.

Top right: breadcrumb line fills flexible available width, icon controls pinned right in order **Open in Folder | Tools | Settings gear**, Lucide icons, descriptive accessible names/tooltips for all buttons (hover/focus, touch accessibility). No native application menu bar. Breadcrumb shows actual complete path with muted ancestors, bright/bold filename, chevron separators, single line; overflow-x auto, hidden horizontal scrollbar **only here**, default scroll to end on open/bank switch/resize when following tail, still manually scrollable. Do not force max-width/min-content or clip filename unnecessarily; copy full path via optional action. No masking overlay hacks. Reveal selected file in native manager (Finder/Explorer, Linux best-effort folder) not launching editor for it; use native Tauri capability, web unavailable explained. Top actions ordinary accessible anchored dropdowns, keyboard navigation, focus return, outside click/Escape/item closes, collision-aware placement (save popup opens upward if needed). Keep menus/dropdowns styling and interaction, avoid custom popup regressions.

Header: centered large map name (prototype 28 logical px) with modest additional gap above (historical vgap 6 plus layout spacing); creator on left and last update/download on right, use real data or Unknown, same horizontal inset as adjacent editor rows. User repeatedly requested Created by inset alignment. Bank file dropdown updates path/model/context; multiple banks hint only if >1, text `Multiple bank files detected. Choose one:` when relevant. No unnecessary divider directly under title; optional separator between overall header and tabs retained only if visual reference calls for it. Do not fabricate author/date/name. Display signature/backup status unobtrusively, include dedicated re-sign action without replacing existing top/bottom controls. Map title remains centered in pane, not shifted by long metadata.

Tabs exact `Simple View`, `Table View`, `Raw View`; no duplicated radio selector or extra cards repeating tab labels/subtitles. Simple View conditional on matched game profile, extra top padding only on Simple content (historical 8px gap, plus existing inset), not Table. Table has separate `Sections` label (keep) and Name/Type/Value headers; no `Entries` label. Scroll/flex grows to full available vertical/horizontal area. Table layout customizable as sidebar or all sections in one long table. Raw has editable XML with syntax highlighting. Maintain equal horizontal inset across header/editor/bottom controls, not stacking arbitrary padding layers. Bottom bar status left, Reset text-only no background, **8px gap** to Save split button furthest right, modest **2px additional bottom gap** matching approved prototype, consistent right inset. No fixed height that prevents growth; settings may change density. Reset and Save disabled or explicit reason when no document/inapplicable. Status should show actual operation completion, not mock success.

## Tools/settings

Tools popup: `Unprotect external map file…`, `Re-sign external bank…`, `Back up all bank files`. Context menu/per-map controls for backup map, restore selected bank, current-bank re-sign, optional open/copy path. Tools operate independently of current bank. Filter external bank `.SC2Bank` (case-insensitive), optional `.xml` if validated; map `.SC2Map`, `.s2ma`, `.mpq` as supported, no arbitrary execution. External re-sign asks player/author handles and target bank name if context not inferable; validation and status. Authorized map repair uses new copy/default safe export and explicit warnings; never automatically modifies cache. Settings gear opens full page; More same route, preserve open editor state. Full page sections: General/path/account, Appearance (system/light/dark, density, text size, consistent theme), Layout (sidebar sizes, grouped/unified table, breadcrumb visibility, raw wrap), Editing (numeric display, validation, undo/history), Saving (auto re-sign, default overwrite, automatic backups, location/retention, confirmations), Advanced (index concurrency, cache refresh/clear, diagnostics, associations, About/version/license). Quick Options are same persistent values, not duplicate state. Manual root selectable even if detection works; explicit auto/manual and Re-scan. No forced system theme; web/native system theme changes supported. Keep user-approved defaults unless expressly changed.

## States and accessibility

Startup shell shown immediately with cancellable discovery progress. Distinct empty states: no SC2 root (exact user copy in discovery spec), no banks yet, no matching search, no selected map/bank, unknown map metadata, invalid/unsupported bank, no profile, file access failure, backup required, signing missing context, external change. No empty map selector or phantom mock data. Focus visible, keyboard shortcuts Cmd/Ctrl+S, standard Undo/Redo, search/focus, Esc dialogs; tooltip not only label. High contrast, no color-only status; screen reader labels, tab navigation, touch-friendly targets on web. Compact design remains usable at different DPI and theme. All operations report success only when real. Record visual snapshots desktop and browser at 850x500, narrow and wide, light/dark. Test dropdowns, sticky bottom/right alignment, breadcrumbs long paths and resizing, real map with multiple files. No unnecessary animations, network images or huge icon bundles. No screenshot with real account data.
