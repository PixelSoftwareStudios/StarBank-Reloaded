# StarBank Reloaded
A StarCraft II bank file editor

## Exposition

[StarBank](https://github.com/BlueRaja/Starbank) is a great piece of software, but it's been around since 2012 and it hasn't been updated in 4 years. It's built for Windows only and is quite dated.

StarBank Reloaded aims to be a cross-platform, modern version of StarBank, for the 15 or so SC2 players still around today.

## Installation

Binaries available in the Releases tab or run `just build`
